Phone only · no computer needed

Remove your TikTok reposts from Safari

This installs a bookmark that isn't a web page — it's a small program. Tap it while you're on TikTok and a control panel slides up from the bottom, scans your reposts, and takes them off one at a time.

It runs inside the tab you're already logged into. It never asks for your password, and nothing it does leaves your phone.

Put it in your bookmarks

  1. 01

    Copy the code above

    Tap the button. If it refuses, open Copy it by hand, tap inside the box, then Select All and Copy.

  2. 02

    Bookmark any page

    In Safari, tap Share → Add Bookmark. Name it Remove reposts and save it to Favorites so it's quick to reach.

  3. 03

    Edit that bookmark

    Tap the open-book icon → Edit → tap the bookmark you just made.

  4. 04

    Replace the address

    Clear the address field, paste, and tap Done. If Safari eats the javascript: at the front, type those characters back in yourself — it won't run without them.

Run it

  1. 05

    Open your own profile

    Go to tiktok.com in Safari, logged in, and tap through to your profile. The address needs to start with /@ — the panel checks.

  2. 06

    Tap the bookmark

    Open the bookmarks list and tap Remove reposts. The panel appears at the bottom of the page.

  3. 07

    Scan, then Remove all

    Scan opens your Reposts tab and scrolls to the end, collecting everything first. Then confirm the count and let it work.

Turn off Auto-Lock before a long run

Settings → Display & Brightness → Auto-Lock → Never. Safari freezes timers when your screen locks or you switch apps, which stalls the run partway through.

If it does stall, nothing is lost — it remembers what already came off. Scan again and it picks up where it stopped.

How it behaves

  • Collects the whole list before removing anything.
  • One at a time, with a random 3–8 second gap. Never in parallel.
  • Checks the repost actually came off before counting it — a tap that quietly did nothing is recorded as a failure, not a success.
  • Three tries each, then it marks that one failed and carries on. One failure never ends the run.
  • Stops at 200 per run by default. You can change that in the panel.
  • Remembers what it removed, so a second run skips those and retries the failures.
  • Slower and more fragile than the desktop version, which drives a real browser and can verify more.
  • If a scan finds nothing, TikTok has changed its page structure. That's a fix that needs a computer.
